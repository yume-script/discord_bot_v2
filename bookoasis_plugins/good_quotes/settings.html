ZenQuotes·PositiveQuotation을 활성화하고 이용 범위를 확인한 뒤 아래 설정 저장 버튼을 누르세요. 대상 확인을 누르면 영문 문구를 서버에 자동 수집합니다. 파일 임포트 없이 미번역 일괄 번역을 실행할 수 있습니다.

DeepL 키를 입력하거나 바꾼 뒤에도 아래 코어 설정 저장 버튼을 눌러야 적용됩니다. 두 영문 공급원의 한국어 없는 문구만 번역하며, Korean Advice와 기존 한국어 번역은 전송하지 않습니다.

신규 Developer의 무료 제공량은 총 100만 자이며 자동 갱신되지 않습니다. 기존 API Free는 월 50만 자입니다. 실제 사용·잔여량은 대상 확인 시 조회합니다.

대상 확인을 눌러 미번역 건수와 예상 문자량을 확인하세요.
